# A股银行投资定量分析框架 — 方法论详解

本文档解释 `bank-investment-analysis` skill 背后的分析逻辑、指标口径、打分规则及其依据。配套实现见 `scripts/bank_analysis.py`，模型常量集中在 `scripts/bank_universe.py`。

> ⚠️ 本框架是**量化研究工具**，输出为相对强弱信号而非预测。不构成任何投资建议。

---

## 0. 投资银行股到底赚什么钱？

投资者买入银行股的收益来自两块：**股价上涨（估值修复 + 净资产内生增厚）和分红**。由此推出银行股定价的第一性原理——由股利贴现模型(DDM)可推导：

```text
P/B = ROE × d / (k − g)

其中 d=分红率, k=股权要求回报率(COE), g=可持续增速(≈ROE×留存率)
简化形态: PB ≈ ROE / COE
```

三个直接推论，构成本框架的全部骨架：

1. **ROE 是估值的锚**：长期看 PB 与 ROE 正相关；买银行股本质是买"ROE 的可持续性与均值回归"。
2. **资产质量决定账面价值的真实性**：不良被隐藏时，报表净资产高估、真实 ROE 低估，市场会要求更高折现率 → 长期破净。因此"拨备覆盖率/不良率"是盈利数据的可信度开关。
3. **分红是与债券竞争的现金流**：银行股具有类固收属性，**指数股息率 − 10Y 国债收益率** 的利差是板块层面的核心配置信号。

参考研究：BIS《The ABCs of bank PBRs》(ROE 与分红率是 PBR 最稳健的解释变量)；国内卖方共识框架(PB-ROE 体系)；东财银行业专题《投资银行股赚什么钱》(收益=ROE×Δ)。

## 1. 框架总览：四层结构

```text
┌─────────────────────────────────────────────────────────────────┐
│ L3 组合层  ETF底仓节奏(温度档位) × 个股卫星(Top评分池) × 类别分散    │
├─────────────────────────────────────────────────────────────────┤
│ L2 个股层  五维截面评分(盈利30/质量25/成长15/资本10/估值20)         │
│            + 资产质量一票否决降档                                  │
├─────────────────────────────────────────────────────────────────┤
│ L1 行业层  行业温度分 = PB分位分×50% + 股债利差分×35% + 动量分×15%   │
├─────────────────────────────────────────────────────────────────┤
│ L0 数据层  东财F10银行专项财务 · 东财个股估值史 · 中证官网指数估值     │
│            腾讯K线 · 10Y国债收益率 · ETF实时清单                   │
└─────────────────────────────────────────────────────────────────┘
```

两个层次的分工：

- **只想投 ETF**（如 512800）→ 只看 L1 温度分定节奏；
- **想选个股** → L1 定总仓位基调，L2 决定买谁、买多少权重。

## 2. L1 行业层：行业温度分（0–100，越高越值得配）

### 2.1 PB 分位分（权重 50%）

- 序列构造：每个交易日取 42 家成分股**等权中位数 PB** （各股 PB 历史来自东财估值史接口，2018 年起约 2100 个交易日）。
- 用中位数而非市值加权：不受大行权重绑架、对新发行股份不敏感、且能代表"典型银行"的估值位置。
- 打分映射（自身历史分位 → 分数，分段线性插值）：

| 历史分位 | ≤10        | 30  | 50  | 70  | ≥90       |
| -------- | ---------- | --- | --- | --- | --------- |
| 得分     | 95(钳制98) | 80  | 60  | 40  | 20(钳制5) |

选择自身历史分位而非绝对阈值的原因：利率中枢下移使整个行业的合理 PB 中枢也在下移，绝对值比较会产生系统性偏差。

### 2.2 股债利差分（权重 35%）

```text
利差 = 中证银行指数股息率(近12个月, 官方csindex口径) − 10Y国债到期收益率
```

| 利差(pp) | ≤0      | 0.5 | 1.0 | 1.5 | 2.0 | ≥2.5        |
| -------- | ------- | --- | --- | --- | --- | ----------- |
| 得分     | 0(钳制) | 25  | 45  | 65  | 80  | 95(钳制100) |

经济学依据：银行持有者相当一部分是"拿股息替代利息"的资金。利差越宽，替代吸引力越强。阈值为经验设定（历史区间大致 −1 ~ +3pp），若利率制度环境变化（如零利率）需整体复核。

### 2.3 动量确认分（权重 15%）

```text
动量分 = clamp(50 + (收盘价/MA250 − 1)×125, 5, 95)
```

用途是缓解纯左侧"越跌越买"的陷阱：价格站上 250 日均线趋势确认时略加码，深跌之下不追加负向太多（钳制在 5），保持框架以估值为主导。

### 2.4 档位与动作

| 温度分 | 档位                  | 参考动作                   |
| ------ | --------------------- | -------------------------- |
| ≥75    | 🔴 低估·积极配置      | 提高配置节奏（如定投加倍） |
| 55–75  | 🟡 偏低·正常定投      | 维持常规买入节奏           |
| 40–55  | ⚪ 中性·持有不加仓    | 只持有不新增               |
| <40    | 🟠 偏热·减持/止盈观察 | 分批兑现或停止买入         |

任一因子数据缺失时剔除该因子并把权重归一化到剩余因子（例如接口故障时退化为双因子）。

## 3. L2 个股层：五维评分

### 3.1 为什么用"同业截面分位数"而不是绝对阈值

银行的监管红线有绝对意义（资本充足率），但经营指标的合理范围随行业景气整体移动（息差下行周期全行业 NIM 都在收窄）。截面打分回答的是"它比同行好多少"，配合维度权重后给出相对排序；绝对红线的约束交给 §3.4 的一票否决处理。

打分细节：中间名百分位（ties 取中点），缺失值跳过并按可用权重**重归一**，整维度缺失则剔除该维度再重归一总分权重（覆盖度一并展示）。

### 3.2 五个维度

#### 盈利能力（30%）— ROE 是估值的锚

| 子项        | 权重 | 方向 | 口径                   |
| ----------- | ---- | ---- | ---------------------- |
| 年化加权ROE | 40%  | 高优 | 加权ROE÷累计期年化系数 |
| 净息差 NIM  | 25%  | 高优 | 最新报告期披露值       |
| 年化ROA     | 15%  | 高优 | 同上年化               |
| 成本收入比  | 20%  | 低优 | 越低运营效率越高       |

年化说明：Q1×4、半年×2、三季×4/3、年报×1。这是线性外推的粗略近似（Q1 通常占全年利润权重略低），用于截面可比，不用于精确预测。

#### 资产质量（25%）— ROE 的"可信度"修正

| 子项             | 权重 | 方向 | 说明                              |
| ---------------- | ---- | ---- | --------------------------------- |
| 不良贷款率       | 35%  | 低优 | 核心资产质量存量指标              |
| 拨备覆盖率       | 35%  | 高优 | 未来利润的蓄水池/藏富能力         |
| 拨贷比           | 10%  | 高优 | 交叉验证拨备厚薄                  |
| 拨备覆盖率同比变化 | 20% | 高优 | 蓄水池消耗速度(pp)，负值=正在放水 |

覆盖率与它的变化方向合计 55% 子权重：存量水平回答"池子里还有多少水"，同比变化回答"是否正在放水"——双位数利润增长若靠消耗拨备反哺，会在后一项现形（v1.1 新增，动因见 research_changshu_2026.md 常熟案例：拨备 -49pct/年 但 v1.0 质量分仍 91.6）。注意免费接口无"关注类占比/逾期率/不良生成率"，这是本框架剩余的最大信息盲区（见 §6）。

#### 成长性（15%）— 增速是 g，影响公式里的分母

| 子项         | 权重 | 方向 | 口径               |
| ------------ | ---- | ---- | ------------------ |
| 归母净利同比 | 60%  | 高优 | 最新报告期累计同比 |
| 营收同比     | 40%  | 高优 | 同上               |

营收给次权重是因为利润可通过拨备反哺轻易调节，营收更难美化。

#### 资本充足（10%）— 分红的原材料

| 子项               | 权重 | 方向 | 口径         |
| ------------------ | ---- | ---- | ------------ |
| 核心一级资本充足率 | 100% | 高优 | 监管红线指标 |

权重刻意压低：它更像"约束项"而非"进攻项"，主要靠 §3.4 的否决线兜底。同时它决定内生性增长上限（g ≤ ROE×留存率×资本空间）与高分红的持续性。

#### 估值吸引力（20%）— 你为什么现在买

| 子项             | 权重 | 方向 | 口径                              |
| ---------------- | ---- | ---- | --------------------------------- |
| PB 自身历史分位  | 30%  | 低优 | 近3年窗口内的经验分位             |
| 相对板块PB溢价   | 25%  | 低优 | 个股PB ÷ 板块中位数PB − 1         |
| PB ÷ 年化ROE     | 25%  | 低优 | 每1个百分点ROE付出的PB            |
| 分红率           | 20%  | 高优 | 近12个月实施现金分红 ÷ 年化归母净利 |

四个子项各司其职：自身分位防追高个股自身的historic区间顶部；相对溢价衡量板块内部贵贱；PB/ROE 把第一性原理 `PB ≈ ROE/COE` 直接转成一个可横比的"性价比商数" （数值越低说明市场给这条 ROE 的定价越便宜）；分红率是类固收逻辑下股东实际落袋的比例（银行持有者相当部分以股息替代利息，同样 20% 分红率的两家银行对配置资金的吸引力不同）。分红率取滚动12个月实施口径（含中期分红，`stock_fhps_detail_em`），与财年宣告口径会有少量差异。

#### 行情参考列（不参与评分）

报告中会同步展示**现价、当日涨跌幅、PE-TTM、PE动态、总市值**，但它们只是行情参考：银行股的定价锚是 PB 与 PB÷ROE，而 PE 受拨备计提、减值损失与利润调节的影响过大（同一资产质量变化可以让 PE 在年度间跳变），因此不纳入打分体系。PE动态 = 总市值 ÷ 最新报告期年化归母净利（一季报×4 / 中报×2 的粗年化）。

### 3.3 总分与档位

```text
基础分 = Σ 维度分 × 维度权重     (缺失维度重归一)
档位: A+ ≥80 > A ≥70 > B ≥60 > C ≥50 > D <50
```

### 3.4 一票否决与强制降档（GATES）

| 条件                                    | 动作            | 依据                            |
| --------------------------------------- | --------------- | ------------------------------- |
| 不良率 > 2.0%                           | 总评强制 ≤ C 档 | 存量包袱重，报表 ROE 可信度打折 |
| 拨备覆盖率 < 130%                       | 总评强制 ≤ C 档 | 接近监管底线，蓄水池已近枯竭    |
| 核心一级 < 8.5%（系统重要性行要求以上） | 再降一档        | 分红与内生扩张受限              |
| 财报距今 > 300 天                       | 标注陈旧告警    | 数据时效风险                    |

设计哲学：**截面分排序可能把"账面好看但质量存疑"的银行排到前排；质量门槛的意义是拒绝让高分建立在不可信的报表上。**

### 3.5 已知截面偏差（读结果时必须记住）

- 各行披露节奏不同（中报季部分行只有一季报），跨行对比存在"报告期不同步"误差。界面上保留每家行的报告期标签，重要决策前自行确认是否对齐。
- 免费数据不含关注类迁徙率等前瞻指标，资产质量维度偏向"历史存量"。

## 4. L3 组合层：怎么用这两个分数

本 skill 输出的不是调仓指令，而是三类**决策输入**：

1. **底仓节奏（ETF）**：按 §2.4 温度档位调整银行 ETF 的定投倍率/止盈计划。底仓解决"要不要在这个时点拥有银行敞口"的问题。
2. **卫星选择（个股）**：在温度允许配置的前提下，从 B 档以上的高分池挑选，结合类型分散度（国有大行/股份行/城商行/农商行）控制个体风险——report 的 Top10 类别分布即为该检查项。
3. **避雷名单**：触发一票否决/降档告警的标的即使排名尚可也应先问原因再谈买入。

风控原则（框架外部执行）：单一个股权重上限、单类银行上限、温度进入"偏热"档后逐步把个股敞口换回 ETF 或现金。

### 字段口径备忘（踩过的坑）

- `BLDKBBL` 字段名带"拨贷比"字样，但实测取值为**拨备覆盖率(%)**（387.76 等），真正的拨贷比(%) 是 `LOAN_PROVISION_RATIO`。已按实测语义映射。
- 三级资本充足率字段：`HXYJBCZL`=核心一级、`FIRST_ADEQUACY_RATIO`=一级、`NEWCAPITALADER`=资本充足率(总)，均以多家银行公开财报交叉验证过量级。
- csindex 的 `市盈率1/市盈率2` 分别对应静态/滚动(TTM)，`股息率1` 取近12个月口径使用。
- 板块 PB 采用成分等权中位数，与官方市值加权 PE 数字不可互相替代，只做自身分位比较。

## 6. 局限与迭代方向

1. **无前瞻资产质量**：缺关注类占比、逾期90天+/不良偏离度、不良生成率。常熟案例（research_changshu_2026.md）证明这是当前量化差异最大的盲区。迭代方向：从中报/年报文本抽解析录，或引入付费数据源字段。
2. **报告期不同步**：未做 TTM 对齐。方向：以最近4个单季度滚动合成统一截止日。
3. **增速趋势不可见**：截面百分位只取单期同比，"19.6%→10.6%"式的换挡不可见。可从按报告期 DataFrame 计算多期斜率，待评估。
4. **~~股息率因子未入个股评分~~（v1.1 已补）**：分红率以滚动12个月实施口径进入估值维度；拨备覆盖率同比变化进入资产质量维度。变更动因与实证案例见 research_changshu_2026.md。
5. **权重/阈值为经验设定**：现版来自理论结构与常识校准，非统计拟合。若积累足够样本（历月快照），可做 IC 测试回检权重——建议仿照 etf-three-factor 的事件锚点思路建立校准 Runbook 后再动模型常量。
6. 单点依赖网络接口，任何一家改版都会导致相应因子退化（脚本会自动降级并提示）。

再次声明：所有输出均为量化研究的相对信号，不构成投资建议；据此交易风险自负。
