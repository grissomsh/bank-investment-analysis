# 买银行股之前，我用 Skill 给自己造了把尺子

> 这篇文章不推荐任何一只银行股，也不告诉你明天该不该买。它讲一套开源工具的思路：怎么判断银行板块贵不贵，哪家银行数据上更扎实，以及为什么"什么时候买"这个问题，工具只能给参考坐标。

## 投银行的人，纠结的其实是同样三件事

不管你是买 ETF 躺平的，还是自己挑个股的，最后都会撞上三个问题：现在贵不贵？买哪只？现在能进场吗？

前两个问题有数据可查，第三个问题没有答案，只有纪律。市面上大部分内容在前两个问题上绕圈，第三个问题要么被神化成"抄底秘籍"，要么一句话带过。这篇文章把三个问题放在一起说：前两个，工具能帮上忙；第三个，工具给刻度，扳机得自己扣。

## 银行股便宜得有点过分，为什么照样有人亏钱

先看几个数字。A 股 42 家上市银行，典型的那一家，股价只有每股净资产的 0.54 倍，相当于标价 100 元的家底，54 元卖给你。同期股息率 4% 出头，十年期国债收益率只有 1.7% 左右，中间差着 2.5 个百分点。

看起来像捡钱，为什么很多人买了没赚钱？因为银行便宜了不是一年两年，是七八年。原因在银行这门生意的记账方式：普通企业卖产品收现金，银行"卖"的是风险，放出去的每笔贷款能不能收回来，要几年后才见分晓。后果有两条：报表上的净资产可能掺水，不良暴露是滞后的；利润可以调节，少提一笔拨备，当期利润立刻好看。

认定口径的威力可以举个例子。两家银行不良率都是 0.9%，一家把逾期 1 天的贷款就算不良，另一家逾期 90 天以上才算。报表一样，风险完全是两回事。所以看银行，PE 和利润增速都是次要的，真正要看的是三样东西：净资产的成色、拨备池的水位，以及市场信不信这份报表。

## 贵不贵：给板块量个体温

我造的第一个工具是个"温度计"，输出 0 到 100 的温度分，回答整个板块此刻的便宜程度。三个读数拼成。

最核心的读数是估值位置。把 42 家银行的市净率排队取中位数（防止几家大行绑架读数），再和这个数自己过去八年比。今天处在 11% 的位置，意思是过去八年里 89% 的时间都比现在贵。注意是和"自己的历史"比，不是和某个固定数值比：利率一直在降，整个行业的合理估值中枢跟着降，死等"PB 回到 0.8"可能永远等不到。

第二个读数是股息率减国债收益率。一大批买银行的人，图的就是拿股息替代利息，差值越宽，替代越划算。现在 2.5 个百分点的利差，历史上算相当厚的。

第三个读数是价格相对 250 日均线的位置，权重压得很低。它的作用是提醒你，便宜的时候趋势往往也难看。"左侧"不是 bug，是这种策略的出厂设置。

三个读数合成温度分，再分四档：很低、偏低、中性、偏热。它衡量的始终是"贵不贵"，不回答"涨不涨"。

## 买哪只：同行打分，外加一票否决

只买 ETF 的话，这节可以跳过。想挑个股，核心方法是同行横比：不问某家银行好不好，问它比另外 41 家好多少。行业景气是一起移动的，息差下行时全行业一起收窄，去年垫底的息差今年可能算中上，设死线没意义，比排名才有信息。

工具从五个方面给 42 家银行打分：挣钱能力（ROE、净息差这些），家底干不干净（不良率、拨备覆盖率，外加一个拨备消耗速度，看池子里的水是满的还是正在放），长不长个儿（利润和营收增速），底子厚不厚（资本充足率），现在买划不划算（PB 位置、相对同行的溢价、每一份 ROE 花多少倍 PB 买、分红率）。

打分之外有一条更硬的规矩：不良率超过 2%，或者拨备覆盖率掉到 130% 以下，总分直接摁到 C 档，分数再高也没用。报表好看的前提是报表可信，可信度存疑的银行，高分本身就是陷阱。

## 什么时候买：工具给刻度，扳机自己扣

三个问题里这个最重要，也最不讨好。入场时间没有任何工具能替你决定，工具能做的，是把"感觉跌得差不多了"换算成一个可核查的数字。

实操里常见两种纪律，工具在其中的角色不一样。

定投派不猜底，按节奏买，温度低的时候多买两份，温度高的时候少买甚至停。适合没时间盯盘、既怕踏空又怕套牢的人。工具每天给你一个温度读数和档位，你定一条自己的规则，比如低估档定投翻倍、偏热档停止，剩下的交给纪律。

超跌入场派平时不动，等极端刻度出现再分批进。什么是极端？比如板块 PB 分位压到 10% 以下，同时股债利差拉到 2.5 个百分点以上。这两个条件同时满足的时刻，八年里也没几天。工具在这里的作用，是避免你在半山腰就把子弹打光。

两种纪律的代价也得说清楚。定投的代价是右侧没有你，底部的筹码永远买不满；超跌入场的代价是信号出现之后可能继续跌，左侧买入意味着账面浮亏，而且可能持续很久。我自己就遇到过：温度分在"低估"档躺了很久，期间指数又阴跌了一截。工具没失灵，左侧策略本来就要吃这一段。

还有一种信息值得看一眼：ETF 的份额变化。价格是二级市场博弈出来的，份额是一级市场真金白银申购赎回的记录。龙头银行 ETF 连续净赎回，说明有人在兑现浮盈。这属于"别人在干什么"的参考，同样只是参考。

仓位怎么分、这笔钱能放几年、浮亏 20% 你睡不睡得着，这些全在工具之外，也全在决定成败。

## 91 分的银行，年报里有另一张脸

这套工具最值钱的一次产出，是一回被证伪的记录。

早期版本里，一家农商行在 42 家银行中总分第一，资产质量维度拿到 91.6 分：不良率行业第二低，拨备覆盖率行业第二高，净息差是同行中位数的 1.6 倍。光看截面数据，无可挑剔。

然后我把它的定期报告原文（巨潮资讯上免费下载的 PDF）一页页翻了一遍，看到了接口里完全没有的东西：逾期贷款两年翻倍，拨备覆盖率一年掉了约 50 个百分点，逾期 90 天以内的"先行桶"半年还在增长，已经进不良的贷款里，往更差等级迁徙的速度在加快。报表的水面很平静，水面下在流动。

我没有手动去改它的分数，那等于作弊。做法是把"拨备消耗速度"做成正式的打分项，让模型自己学会看这个维度。新版本里，这家银行的资产质量分从 91.6 降到 74.4，还是第一，但不再是无可挑剔的第一。同一个版本里，高分红的大行在估值项拿到了之前没有的加分。

这件事之后我对这套工具的定位更清楚了：分数会错，方法不能重复错。让它当着你的面认错一次，比让它多对十次更有用。

## 想自己跑一套：三条命令的事

这套东西做成了 Claude Code 的 Skill，本质是几个 Python 脚本加一份说明文件，只依赖免费的公开接口。上手三步。

第一步，拉仓库，跑部署脚本。它会把脚本装到家目录的 ~/.bank-skill，自动建虚拟环境、装好 akshare：

```bash
git clone https://github.com/grissomsh/bank-investment-analysis.git
cd bank-investment-analysis && bash setup.sh
```

第二步，收盘后跑一次分析，一两分钟。它会输出行业温度、42 家银行的评分表，并在 ~/.bank-skill/workspace/ 下生成 HTML 报告和 JSON 数据，也就是本文说的温度卡、五维评分表和 ETF 份额追踪那一套：

```bash
~/.bank-skill/venv/bin/python ~/.bank-skill/scripts/bank_analysis.py
```

几个顺手的开关：--healthcheck 先查六路数据源通不通；--detail 600036 看某家银行的完整体检单；--report 601128 自动下载这家银行的年报中报 PDF 并按年份归档，方便你对照前面说的"接口看不到的另一张脸"。

第三步，其实可以没有命令。因为它是个 Skill，你也可以直接在 Claude Code 里说"跑一下今天的银行分析"或者"给招商银行做个体检"，Claude 会替你执行脚本，再把结果讲成人话。命令行党和对话党，都能伺候。

## 它做不到的事

有几句话说在前头免得误导。关注类贷款、逾期结构这些前瞻指标，免费接口拿不到，只能翻年报，所以资产质量评分永远是近似的。各银行出报告的时间参差不齐，横比存在时间差。两家报表相似但价格差三成的银行，差价里的"信任折价"是模型算不出来的。五个维度的权重是我拍的经验值，不是回归拟合出来的科学常数。

所以这套体系输出的是相对强弱信号，不是预测，也不是建议。信号会被盲区扭曲，也会对"市场为什么不信这份报表"保持沉默。把它开源出来，是因为可复现的工具比权威的结论更经得起时间，所有数据源、模型参数和踩过的坑都在仓库里，欢迎检验、质疑和证伪。

工具负责把事实摆整齐。什么时候扣扳机，永远是你自己的事。
